선택과 검증된 성분 토큰으로 만든 통제 프로필만 저장합니다.

## 3. 민감정보

알레르기, 임신·수유 여부 등 개인과 연결된 건강 관련 정보는 민감정보에
해당할 수 있습니다. 해당 기능을 출시하려면 별도 동의 UI, 선택 처리,
동의 철회 및 즉시 삭제 절차를 실제 구현한 뒤 이 항목을 갱신해야 합니다.
현재 공개 기능에서 별도 동의를 받지 않는다면 이 입력을 수집·저장하지 마세요.
현재 구현은 해당 별도 동의가 준비되기 전까지 알레르기·임신·수유 표현이
포함된 공개 추천 요청을 저장 전에 거절하고, 회피 성분명만 입력하도록 안내합니다.

## 4. 제3자 제공과 처리위탁

- 상품 판매·결제·배송·교환·환불은 사용자가 선택한 외부 판매처가 담당합니다.
- 현재 제휴 네트워크에는 판매처가 승인한 링크와 사전 설정된 캠페인 값만 전달하며, 서비스 내부 클릭 ID는 전송하지 않습니다.
- 개인을 식별할 수 있는 정보를 제휴사에 제공하는 기능을 추가할 경우,
  제공받는 자·목적·항목·보유기간·거부권을 고지하고 필요한 동의를 받아야 합니다.
- 실제 사용하는 클라우드, 분석, 고객지원 제공자를 `[처리위탁 목록]`에 기재하세요.
- YouTube 관련 영상 기능은 필수 서비스 이용조건·개인정보 처리 안내에 동의한 뒤 제품명을 YouTube Data API에 전송하며 피부 답변, 세션 ID, 이름, 연락처를 보내지 않습니다. YouTube 썸네일을 이용자 기기에서 불러올 때 Google이 IP 주소, 브라우저 정보, 요청 시각 등 네트워크 정보를 처리할 수 있습니다. 이 기능을 사용하면 [YouTube 이용약관](https://www.youtube.com/t/terms)에 따르는 데 동의하며 [Google 개인정보처리방침](https://policies.google.com/privacy)이 적용됩니다.

## 5. 자동 수집 장치

로그인 없는 세션 유지와 보안을 위해 같은 출처 웹에서는 HTTP-only 세션
쿠키를, 별도로 승인한 전용 웹 도메인과 Apps in Toss 클라이언트에서는 웹/앱 저장소의 무작위
세션 토큰을 사용합니다. 토큰은 최대 30일마다 교체되고 앱의 데이터 삭제
기능을 실행하면 서버 데이터와 로컬 토큰을 함께 제거합니다. 이용자가 쿠키나
앱 저장소를 직접 삭제하면 찜·비교 등 일부 기능이 초기화될 수 있습니다.
광고·제휴 추적용 제3자 쿠키는 판매처 이동 후 각 판매처와 제휴 네트워크의
정책에 따라 처리됩니다.

## 6. 이용자의 권리

이용자는 앱의 초기화/탈퇴 기능 또는 `[담당 이메일]`을 통해 열람, 정정,
삭제, 처리정지, 동의 철회를 요청할 수 있습니다. 본인 확인이 필요한 경우
요청 처리에 필요한 최소한의 정보만 별도로 안내합니다.

## 7. 안전성 확보조치

- 세션 식별자의 HMAC 해시 처리
- HTTPS 전송, secure/HTTP-only 쿠키
- 제휴 리디렉트의 서명·만료 검증과 목적지 도메인 allowlist
- 운영 비밀값을 배포 환경의 secret manager에 보관
- 관리자 API 인증, 요청 빈도 제한, 오류 로그의 개인정보 제거
- 만료 데이터 정기 삭제
