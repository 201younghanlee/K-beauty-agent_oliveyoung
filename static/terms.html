서비스 이용조건

K-Beauty Agent는 화장품 선택을 돕는 정보 제공 서비스입니다. 의료 진단이나 치료, 판매처의 가격·재고 보증을 제공하지 않습니다.

추천과 외부 정보

추천은 제공된 피부 조건과 확인 가능한 상품·성분 자료를 바탕으로 생성됩니다. 실제 성분표, 피부 반응, 가격, 재고, 배송 조건은 브랜드와 판매처에서 다시 확인해 주세요. 외부 사이트와 영상의 내용 및 거래는 각 제공자의 조건과 정책을 따릅니다.

YouTube 관련 영상 기능

이 기능은 제품명에 맞는 공개 YouTube 검색 결과를 보여주며, 영상 속 실제 사용 여부, 독립성 또는 광고 여부를 K-Beauty Agent가 보증하지 않습니다. 이 기능을 사용하면 YouTube 이용약관에 구속되는 데 동의하는 것으로 처리되며, Google 개인정보처리방침도 적용됩니다. 협찬·유료 광고 표시는 영상에서 직접 확인해 주세요.

제휴 링크

제휴 표시가 있는 판매처 링크를 통해 구매하면 운영자가 수수료를 받을 수 있습니다. 제휴 여부는 추천 순위를 높이는 근거로 사용하지 않습니다.

문의와 변경

베타 문의는 GitHub 프로젝트에서 받습니다. 민감한 개인정보는 공개 이슈에 작성하지 마세요. 기능이나 법적 요구사항이 바뀌면 이용조건을 갱신하고 버전을 표시합니다.
